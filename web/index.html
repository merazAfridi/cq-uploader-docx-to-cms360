    How to mark your questions

    1. Type a marker above each questionOn its own line: Q1 above question 1, Q2 above question 2, and so on. Enter or Shift+Enter both work.
    2. No end line neededEach question runs down to the next marker. The last one runs to the end of the file. If something follows it that you don't want, such as an answer key, type End on its own line after the last question.
    3. Save as .docx and uploadEach question is captured as it looks in Word, including tables and pictures. The marker lines are left out.

    Also understood: Q 1, Q-1, Q.1, Ques 1, Bangla digits like Q১, and the older Q 1 Starts / Q 1 Ends. The number in the marker becomes the file number.

    Example
    Q1 ১। নিচের শব্দগুলোর অর্থ লেখো: (১×৫ = ৫) দুর্গ, চামর, তিরন্দাজ, অদ্ভুত, স্বাধীন Q2 ২। শূন্যস্থান পূরণ করো: (১×৫ = ৫) ক. জলময় শৈবাল——টাকশাল। খ. দুখু কাঁদতে কাঁদতে——পিছু পিছু গেল।

    Upload to CMS360

    Each image becomes a child group question under the parent, with the image in its Paragraph. Children are added in question order: Ques 1 first, then Ques 2, and so on. Each child gets the marks in the Marks box under its image above. Marks are filled in from the bracket at the end of the question heading, like (১+১+৮ = ১০). If a question has none, its box is red and empty until you type them. You can change any of them.

    To get it: open CMS360 in Chrome, press F12, go to Network, click any request to api.10minuteschool.com, and under Request Headers copy what comes after authorization: Bearer. Chrome replaces its token every 10–30 minutes, so paste a fresh one right before uploading. It's saved only on this computer, in secrets/.env.
